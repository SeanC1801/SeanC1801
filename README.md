## Backend AI Engineering — FlyRank Internship

</div>

**Core goal:** build reliable server-side AI systems — retrieval, structured output, and eval harnesses — that survive real use.

- **API contracts** — define endpoints, payloads, status states, and error responses before implementation
- **Task design & prompting** — turn an ambiguous AI idea into a specific job with boundaries, schemas, and success criteria
- **Retrieval & grounding** — add source context when needed and evaluate whether the answer is actually supported
- **Evaluation & operations** — build a lightweight rubric, handle auth and retries, and document what to monitor in production
